Ensure fonts are embedded in all PDFs. Minimum body text size is 9pt for readability. Document Title Cormorant Garamond 28–36pt Semibold 600 Section Heading Cormorant Garamond 20–24pt Semibold 600 Sub-heading Cormorant Garamond 16–18pt Semibold 600 Body Copy DM Sans — The body text of all printed materials should use DM Sans at a light weight with generous line spacing for comfortable reading. 10–11pt Light 300, leading 15pt Caption / Footnote DM Sans — Smaller supporting text for captions, footnotes, source attributions, and legal copy. 8–9pt Light 300 Label / Tag Holistic Consulting Institute 7–8pt Semibold 600, uppercase Print Typography Rules Minimum body text: 9pt (10pt preferred) Minimum caption text: 7pt Line-height for body: 140–150% of font size (e.g., 10pt text / 14pt leading) Always embed fonts in PDF exports — never rely on system fonts Use Charcoal #2D3436 for body text, never pure black #000000 Paragraph spacing: 6pt after for body, 12pt before headings 03 Logo Usage for Print Clear space, minimum sizing, and placement rules for all printed and digital documents. Do ✓ Use Charcoal #2D3436 for body text instead of pure black ✓ Maintain minimum clear space around the logo at all times ✓ Use Cormorant Garamond for headings and DM Sans for body — always pair them ✓ Use the gold accent line under section labels consistently ✓ Embed fonts in all PDFs before sharing ✓ Use CMYK color values for all professional print jobs ✓ Keep generous white space — let the design breathe Don’t × Use default blue/indigo as a brand color — always use Emerald or Gold × Stretch, rotate, or recolor the logo in any way × Use the same font for both headings and body text × Place the logo on busy backgrounds without sufficient contrast × Set body text smaller than 9pt in print or 14px on screen × Use low-resolution images (below 300 DPI) for printed materials × Crowd slides with text — 6 lines maximum per slide Holistic Consulting Print & Collateral Guide Companion to the Web Brand Guide February 2026
