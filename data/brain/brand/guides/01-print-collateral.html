Print Typography Rules

  • Minimum body text: 9pt (10pt preferred)
  • Minimum caption text: 7pt
  • Line-height for body: 140–150% of font size (e.g., 10pt text / 14pt leading)
  • Always embed fonts in PDF exports — never rely on system fonts
  • Use Charcoal #2D3436 for body text, never pure black #000000
  • Paragraph spacing: 6pt after for body, 12pt before headings

Do’s & Don’ts

Common mistakes to avoid across all branded materials.

Do

✓

Use Charcoal #2D3436 for body text instead of pure black

✓

Maintain minimum clear space around the logo at all times

✓

Use Cormorant Garamond for headings and DM Sans for body — always pair them

✓

Use the gold accent line under section labels consistently

✓

Embed fonts in all PDFs before sharing

✓

Use CMYK color values for all professional print jobs

✓

Keep generous white space — let the design breathe

Don’t

×

Use default blue/indigo as a brand color — always use Emerald or Gold

×

Stretch, rotate, or recolor the logo in any way

×

Use the same font for both headings and body text

×

Place the logo on busy backgrounds without sufficient contrast

×

Set body text smaller than 9pt in print or 14px on screen

×

Use low-resolution images (below 300 DPI) for printed materials

×

Crowd slides with text — 6 lines maximum per slide
